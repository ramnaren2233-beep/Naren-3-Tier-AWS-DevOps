## 🏗️ Project Architecture

This project demonstrates the implementation of a three-tier architecture on AWS along with DevOps practices.

### Tiers

- 🌐 Web Tier
- ⚙️ Application Tier
- 🗄️ Database Tier

### AWS Services

- Amazon VPC
- EC2
- IAM
- S3
- RDS
- Application Load Balancer
- Auto Scaling
- CloudWatch
- Route 53
- Security Groups
